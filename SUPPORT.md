# Suporte do BlackHole+

**Aplicativo na Microsoft Store:** BlackHole Plus  
**Desenvolvedor e editor responsável:** BlackHolePlus  
**Repositório oficial:** [FoxGames2026/BlackHolePlus](https://github.com/FoxGames2026/BlackHolePlus)

## Como entrar em contato

Use o [canal de suporte no GitHub Issues](https://github.com/FoxGames2026/BlackHolePlus/issues) para relatar um erro, pedir ajuda ou sugerir uma melhoria ao desenvolvedor.

É necessário entrar em uma conta GitHub para publicar um pedido de suporte.

Ao abrir um pedido, informe:

1. A versão do aplicativo e do Windows.
2. O que você estava tentando fazer.
3. A mensagem de erro, se houver.
4. Os passos que levam ao problema.

Esse canal é público. Remova dados pessoais e caminhos de arquivos que não queira divulgar antes de anexar uma captura ou registro. Não é necessário enviar seus vídeos para pedir ajuda.

## Biblioteca e reprodução

O BlackHole+ usa arquivos de vídeo locais escolhidos pelo usuário. Para começar, abra a biblioteca e selecione a pasta dos seus vídeos. Se um arquivo não reproduzir, informe seu formato e codec no pedido de suporte; a extensão do arquivo, sozinha, não garante compatibilidade.

## Privacidade

Consulte a [política de privacidade do BlackHole+](PRIVACY.md). Dúvidas sobre os dados locais do aplicativo também podem ser encaminhadas pelo canal de suporte, sem publicar a biblioteca ou seus arquivos pessoais.
