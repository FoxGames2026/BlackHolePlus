# BlackHole+

**Nome na Microsoft Store:** BlackHole Plus  
**Desenvolvedor e editor:** BlackHolePlus  
**Conta responsável por este repositório:** FoxGames2026

Este é o repositório oficial de informações e suporte do BlackHole+, mantido pelo desenvolvedor BlackHolePlus. A conta FoxGames2026 mantém estas páginas para o aplicativo cadastrado com o nome BlackHole Plus na Microsoft Store.

## Sobre o aplicativo

BlackHole+ é um aplicativo para Windows que organiza e reproduz a biblioteca de vídeos locais escolhida pelo usuário. Ele abre em uma janela própria e oferece biblioteca, busca, lista pessoal, progresso de reprodução e legendas WebVTT adjacentes ao vídeo.

Os vídeos pertencem à biblioteca do próprio usuário e permanecem nas pastas escolhidas por ele.

## Disponibilidade

A versão para Windows está em processo de certificação na Microsoft Store. Este texto não representa confirmação de aprovação ou publicação.

O pacote atual destina-se a Windows 10 versão 1809 ou posterior e Windows 11, em computadores x64. A compatibilidade de reprodução depende do formato e do codec do vídeo.
